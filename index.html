01 About

I'm Brianna, and I like turning messy, human information into things you can search, map, and explore. My work sits between data and people: how we describe cultures, how we catalog knowledge, and how a little code can make both easier to see.

I've clustered 141 societies with K-Modes, put the world's domesticated animals on an interactive map, and built a library catalog from the database up. I learn by building, and I keep building.
