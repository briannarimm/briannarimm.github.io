CodePix is a visual-novel textbook. The learner is a new apprentice at a workshop that repairs talking appliances. Each job teaches one idea, and the learner then tries it for real in a terminal on their own computer.

## What it covers

**Module A: Python.** The terminal, bits and bytes, variables, loops, functions, files, tests, and a small program of the learner's own.

**Module B: Machine learning.** Fitting a line, measuring mistakes, telling yes from no, avoiding self-deception in evaluation, and a look inside neural networks. Module B unlocks after Module A.

## Use it

The game runs in a web browser. No Python runs in the page: every output shown was recorded from real Python. Progress saves in the browser only. All shops, people, and data are fictional.

## How it was made

This project was built with Claude Code, an AI coding assistant, under Brianna Imm's direction. The repository describes the sources and the process.
