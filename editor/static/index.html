Basics

Visibility

Links

The first link is the main button on the item page. Cards always link to the item page and show these links as extra buttons.

Thumbnail

Shows on cards and in link previews. A 16:10 image works best.

Drop an image here, or choose a file

Gallery (carousel)

Feature images for the item page. Independent of the thumbnail. With no gallery, the item page shows the thumbnail.

Drop images here, or choose files

Files

Downloads such as a PDF. A link can point to one of these files.

Drop files here, or choose files

Page text

Markdown. Use ## Heading, **bold**, *italic*, - list, and [link](https://...).

Dublin Core

Title, Description, and Date come from the fields above. For fields with more than one value, put each value on its own line.

Publishing commits to on main. GitHub Pages then rebuilds the site.
